# تطبيق طبيب الغيط (Tabib El-Gheit) 🌾🌿

تطبيق محمول متكامل لتشخيص أمراض النباتات والمحاصيل الزراعية بالذكاء الاصطناعي، تم تصميمه بالكامل ليعمل باللغة العربية مع دعم الاتجاه من اليمين لليسار (RTL).

---

## 🚀 كيفية تنزيل ملف الـ APK على هاتفك في 3 دقائق مجاناً:

تم إعداد أتمتة سحابية كاملة عبر **GitHub Actions** تقوم بتجميع التطبيق وإخراج ملف `APK.` تلقائياً دون الحاجة لتثبيت أي برامج أو أدوات أندرويد على جهازك:

### الخطوة 1: إنشاء مستودع جديد على GitHub
1. ادخل على [GitHub](https://github.com/new) وأنشئ مستودعاً جديداً (New Repository) وسمّه مثلاً: `tabib-el-gheit`.
2. انسخ رابط المستودع (مثال: `https://github.com/username/tabib-el-gheit.git`).

### الخطوة 2: رفع الكود بـ 3 أوامر فقط
افتح موجه الأوامر (PowerShell أو Terminal) داخل مجلد المشروع ونفّذ:
```bash
git remote add origin https://github.com/YOUR_USERNAME/tabib-el-gheit.git
git branch -M main
git push -u origin main
```

### الخطوة 3: تحميل الـ APK فوراً من GitHub
1. افتح صفحة المستودع على GitHub واضغط على تبويب **Actions** في الأعلى.
2. ستجد عملية البناء تعمل تلقائياً تحت اسم: **Build Android APK (طبيب الغيط)**.
3. خلال نحو دقيقتين إلى 3 دقائق، ستتحول العلامة إلى اللون الأخضر (مكتمل).
4. اضغط على عملية البناء ومرر لأسفل إلى قسم **Artifacts**، ستجد ملفاً باسم:
   👉 **`tabib-el-gheit-apk`**
5. اضغط عليه لتحميله مباشرة إلى هاتفك وتثبيته! 🎉

* **تقرير التشخيص:** عرض دقة الفحص بالنسبة المئوية، درجة الخطورة، العلاج الحيوي العضوي، المبيدات الكيميائية الموصى بها، وطرق الوقاية.
* **موسوعة الآفات الزراعية:** محرك بحث وفلاتر ذكية لأشهر أمراض المحاصيل.
* **الملف الشخصي:** إدارة بيانات المزرعة، التنبيهات، والخط الساخن للإرشاد الزراعي.
